# Support

Use [GitHub Issues](https://github.com/Ettacent/NimarkoGram/issues) for reproducible bugs and feature proposals. Include the NimarkoGram version, device model, Android version and exact reproduction steps.

Reports and questions are accepted in English, Russian and Chinese.

Use [GitHub Discussions](https://github.com/Ettacent/NimarkoGram/discussions) for development questions and general project discussion.

Do not publish credentials, signing material, phone numbers, private messages or unredacted logs. Security vulnerabilities must be reported through a [private security advisory](https://github.com/Ettacent/NimarkoGram/security/advisories/new).
