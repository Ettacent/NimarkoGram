## 🇷🇺 Русский

### Что нового

- Чейнджлог в автообновлении теперь выбирается по языку приложения. Сохранена совместимость со старыми версиями клиента.
- Стандартная камера Telegram используется по умолчанию. Ранее выбранная пользователем камера сохраняется.

### Камера и кружки

- Исправлена искажённая картинка широкоугольной камеры Camera2 при записи кружков на OPPO CPH2791.
- Исправлен выбор поддерживаемых режимов стабилизации и коррекции изображения в Camera2.
- Исправлено освобождение ресурсов при ошибке запуска записи кружка.
- Исправлено завершение записи CameraX: освобождение камеры больше не зависит от загрузки миниатюры, а отменённая запись не сохраняется после повторной остановки.

### Сообщения и интерфейс

- Исправлено зависшее размытие списка чатов после переключения аккаунта.
- Исправлено мерцание значка счётчика пересылок рядом с просмотрами при подсветке результатов поиска.
- Исправлено положение индикатора ожидания при отправке и редактировании сообщений с медиа.
- Переработано взаимодействие с медиа под спойлером: сначала раскрывается содержимое, затем становятся доступны кнопки управления.
- Исправлена форма заливки аватара архива при использовании некруглых аватаров.
- Исправлено освобождение старых анимированных обоев при смене фона.

### Пересылка, черновики и ссылки

- При смене получателя пересылки сохраняется выбор сообщений из предпросмотра.
- Исправлено сохранение изменений форматирования, ссылок и эмодзи в черновиках, когда сам текст не менялся.
- Исправлена потеря цитаты в отдельных сценариях отправки фотографии.
- GIF и стикеры из клавиатуры сохраняют выбранные параметры отложенной отправки.
- Редактор ссылки теперь подставляет её текущий адрес; для новой ссылки используется `https://`.
- Пути вроде `/usr/bin` больше не распознаются как команды бота.

### Медиа и загрузки

- Копирование файла из системного меню «Поделиться» перенесено в фон. Добавлена обработка отмены и очистка неполных копий при ошибке.
- Ошибка загрузки раскадровки видео больше не помечает основное видео как неудачную загрузку.
- Исправлен лимит одновременно отправляемых частей файлов, в том числе после смены сети.
- Видео без аудиодорожки больше не останавливает воспроизведение другой музыки внутри клиента.
- Добавление музыки в профиль подтверждается только после успешного сохранения на сервере.
- Исправлена обработка системной команды остановки плеера.

### Эмодзи и плагины

- Исправлена повторная загрузка данных кастомных эмодзи после сетевой ошибки.
- Бесплатные кастомные эмодзи больше не превращаются в служебные ссылки при включённых локальных эмодзи.
- Служебные ссылки локальных эмодзи скрыты из раздела общих ссылок.
- Исправлено освобождение ресурсов анимированных эмодзи в кнопках ботов и элементах интерфейса.
- Исправлены конфликты имён модулей при загрузке плагинов.
- Исправлена работа фильтров хуков, вложенных вызовов и контроля зависаний плагинов.

### Другие исправления

- Ограничено ожидание геолокации при получении погоды для историй.
- Исправлено состояние переключателей после удаления прокси.

## 🇬🇧 English

### What's new

- In-app update notes now follow the app language, while remaining compatible with older clients.
- Telegram's standard camera is now the default. Existing camera preferences are preserved.

### Camera and video messages

- Fixed distorted Camera2 ultrawide video messages on OPPO CPH2791.
- Fixed selection of supported Camera2 stabilization and distortion-correction modes.
- Fixed resource cleanup when video-message recording fails to start.
- Fixed CameraX recording completion: camera release no longer waits for thumbnail loading, and stopping again does not save a cancelled recording.

### Messages and interface

- Fixed blur remaining over the chat list after switching accounts.
- Fixed flickering of the forwards-count icon beside views while search results are highlighted.
- Fixed the pending indicator position when sending or editing media messages.
- Reworked controls for spoiler-covered media: reveal the content first, then access playback and download controls.
- Fixed the archive avatar fill shape when non-circular avatars are used.
- Fixed cleanup of old animated wallpapers when changing the background.

### Forwarding, drafts and links

- Changing the forwarding recipient now preserves the messages selected in the preview.
- Fixed saving formatting, link and emoji changes in drafts when the text itself is unchanged.
- Fixed quotes being lost in some photo-sending flows.
- GIFs and stickers sent from the keyboard preserve the selected scheduled-send options.
- The link editor now fills in the existing link address; new links start with `https://`.
- Paths such as `/usr/bin` are no longer recognized as bot commands.

### Media and transfers

- File copying from the system Share menu now runs in the background, with cancellation handling and cleanup of incomplete copies on error.
- A failed video storyboard download no longer marks the main video download as failed.
- Fixed the limit on concurrently uploaded file parts, including after network changes.
- Videos without an audio track no longer interrupt other music playing in the client.
- Adding music to a profile is confirmed only after it is successfully saved on the server.
- Fixed handling of the system player Stop command.

### Emoji and plugins

- Fixed retrying custom emoji metadata loading after a network error.
- Free custom emoji no longer turn into internal links when local emoji are enabled.
- Internal local-emoji links are hidden from shared links.
- Fixed animated emoji resource cleanup in bot buttons and interface elements.
- Fixed module-name conflicts when loading plugins.
- Fixed hook filters, nested calls and plugin watchdog handling.

### Other fixes

- Added a timeout for waiting on location when fetching weather for stories.
- Fixed switch states after deleting a proxy.

## 🇨🇳 简体中文

### 新增内容

- 应用内更新日志现在根据应用语言显示，同时兼容旧版客户端。
- 默认使用 Telegram 标准相机，保留用户已有的相机选择。

### 相机与视频消息

- 修复 OPPO CPH2791 使用 Camera2 超广角录制圆形视频消息时画面失真的问题。
- 修复 Camera2 防抖和畸变校正模式的支持检测与选择。
- 修复圆形视频消息录制启动失败时的资源释放。
- 修复 CameraX 录制结束逻辑：释放相机不再等待缩略图加载，重复停止操作不会保存已取消的录制。

### 消息与界面

- 修复切换账号后聊天列表仍被模糊效果覆盖的问题。
- 修复搜索结果高亮时，浏览量旁转发计数图标闪烁的问题。
- 修复发送或编辑媒体消息时等待指示器的位置。
- 调整剧透媒体的操作逻辑：先揭示内容，再显示播放和下载控件。
- 修复使用非圆形头像时归档头像填充形状不一致的问题。
- 修复更换背景时旧动态壁纸的资源释放。

### 转发、草稿与链接

- 更换转发接收者时，保留在预览中选择的消息。
- 修复正文未变化时，草稿中的格式、链接和表情修改无法保存的问题。
- 修复部分照片发送流程中引用丢失的问题。
- 从键盘发送 GIF 和贴纸时保留所选的定时发送参数。
- 链接编辑器现在自动填入已有链接地址，新链接以 `https://` 开头。
- `/usr/bin` 等路径不再被识别为机器人命令。

### 媒体与传输

- 系统分享菜单中的文件复制改为后台执行，支持取消处理，并在出错时清理不完整的副本。
- 视频分镜预览下载失败不再导致主视频被标记为下载失败。
- 修复同时上传的文件分块数量限制，包括切换网络后的情况。
- 无音轨视频不再中断客户端内其他音乐的播放。
- 只有服务器成功保存后，才确认已将音乐添加到个人资料。
- 修复系统播放器停止指令的处理。

### 表情与插件

- 修复网络错误后自定义表情元数据加载的重试。
- 启用本地表情时，免费自定义表情不再转换为内部链接。
- 本地表情的内部链接不再显示在共享链接中。
- 修复机器人按钮和界面元素中动态表情的资源释放。
- 修复加载插件时的模块名称冲突。
- 修复钩子过滤器、嵌套调用和插件卡死监控的处理。

### 其他修复

- 为动态故事获取天气时的定位等待添加超时限制。
- 修复删除代理后开关状态不正确的问题。
