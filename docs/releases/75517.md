# NimarkoGram 12.10.1 (75517)

## 🇷🇺 Русский

- Переработана защита плагинов: меньше ложных переходов в безопасный режим, отдельные отчёты и указание проблемного плагина, когда его удалось определить.
- Исправлен зум CameraX и скачок превью при переключении камеры.
- Исправлен чёрный экран кружка после возврата из комментариев.
- Исправлено смещение рейтинга при открытии профиля из плашки с информацией о пользователе.
- Азиатский релей временно отключён: подключения направляются через европейский узел.
- Клиент обновлён до Telegram 12.10.1.
- Исправлено мерцание реакций и полосы над комментариями при раскрытии цитат.
- Улучшена чёткость предпросмотра больших цитат.
- Исправлены начальные цвета QR-кода; фон и элементы страницы теперь появляются плавно.

---

## 🇬🇧 English

- Reworked plugin protection: fewer false safe-mode activations, separate error reports, and identification of the responsible plugin when possible.
- Fixed CameraX zoom and preview jumps when switching cameras.
- Fixed round videos turning black after returning from comments.
- Fixed the rating badge shifting when opening a profile from the user information card.
- Temporarily disabled the Asian relay; connections now use the European node.
- Updated the client to Telegram 12.10.1.
- Fixed reactions and the divider above comments flickering when expanding quotes.
- Improved preview sharpness for large quotes.
- Fixed initial QR-code colors; the page background and interface elements now appear smoothly.

## 🇨🇳 简体中文

- 重构插件保护机制：减少安全模式误触发，提供独立错误报告，并在能够确认时标明导致问题的插件。
- 修复 CameraX 缩放失效及切换摄像头时预览画面跳变的问题。
- 修复从评论返回后圆形视频消息黑屏的问题。
- 修复从用户信息卡片打开个人资料时评分标识偏移的问题。
- 暂时停用亚洲中继，连接改用欧洲节点。
- 客户端更新至 Telegram 12.10.1。
- 修复展开引用时消息回应和评论上方分隔线闪烁的问题。
- 提升大型引用图片的预览清晰度。
- 修复二维码初始配色，页面背景和界面元素现在会平滑显示。
