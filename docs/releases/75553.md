# NimarkoGram 12.10.5 · 75553

## 🇷🇺 Русский

### Что нового

- Добавлена анимация навигации Material с поддержкой жеста назад и перехода из чата в профиль. При обновлении она выбирается по умолчанию; другой вариант можно вернуть в настройках.
- Переработан зум кружков: плавное пружинное изменение масштаба одним и двумя пальцами, сохранение зума после отпускания и быстрая смена направления.
- Добавлена настройка «Плавное переключение модулей камеры» для переходов между широкоугольной и основной камерой. Доступна при выборе CameraX.

### Камера

- Исправлены случаи резкого завершения перехода между модулями при задержке нового кадра.
- Уточнена обработка быстрых изменений зума, обратных жестов и смены сессии камеры.

### Медиа и интерфейс

- Исправлено дублирование фотографии при возврате из просмотра в чат.
- Исправлена обрезка возвращаемого изображения у верхней панели и закреплённого сообщения.
- Исправлено обновление подложки Liquid Glass при закрытии просмотра медиа.
- Исправлено повторное появление эффекта спойлера и лишней анимации загрузки у уже загруженных фотографий в общих медиа.
- Исправлена смена цветов кнопки загрузки файла при открытии чата.
- Уведомление о перезапуске поднято над системной панелью; текст сокращён на всех встроенных языках.

### Стикеры и анимации

- Исправлены причины зависания загрузки анимированных стикеров при ошибке или отмене создания кэша.
- При ошибке кэширования предусмотрено воспроизведение без кэша, без бесконечных повторных попыток.
- Исправлено освобождение ресурсов и обработка отмены фоновых задач анимированных стикеров и WebM.

## 🇬🇧 English

### What's new

- Added Material navigation with back-gesture support and chat-to-profile transitions. It becomes the default on update; another style can be selected in settings.
- Reworked video-message zoom: smooth spring-based control with one or two fingers, persistent zoom after release and responsive direction changes.
- Added “Smooth camera module transitions” for ultrawide/main-camera handoffs. Available when CameraX is selected.

### Camera

- Fixed module transitions ending abruptly when the new camera frame arrives late.
- Improved handling of rapid zoom changes, reversed gestures and camera-session changes.

### Media and interface

- Fixed duplicate photos during the return transition from the media viewer to a chat.
- Fixed returning-image clipping around the header and pinned message.
- Fixed Liquid Glass backdrop refresh when closing the media viewer.
- Fixed spoiler effects restarting and redundant loading animations over already loaded photos in shared media.
- Fixed file-download button colours changing when opening a chat.
- Moved the restart notice above the system navigation area and shortened its text in all bundled languages.

### Stickers and animations

- Fixed causes of animated stickers getting stuck loading when cache creation fails or is cancelled.
- Added playback without cache after a cache failure, avoiding endless retries.
- Fixed resource cleanup and background-task cancellation for animated stickers and WebM.

## 🇨🇳 简体中文

### 新增内容

- 新增 Material 导航动画，支持返回手势和从聊天进入个人资料的过渡。更新后默认启用，可在设置中选择其他样式。
- 重新设计圆形视频消息的变焦：单指和双指均采用平滑弹簧过渡，松手后保留倍率，并及时响应方向变化。
- 新增“平滑切换摄像头模组”，用于超广角与主摄之间的过渡。仅在选择 CameraX 时显示。

### 相机

- 修复新画面延迟到达时，镜头切换过渡突然结束的问题。
- 改进快速变焦、反向手势和相机会话切换的处理。

### 媒体与界面

- 修复从媒体查看器返回聊天时照片重复显示的问题。
- 修复返回中的图片在顶部栏和置顶消息区域的裁剪。
- 修复关闭媒体查看器时 Liquid Glass 背景的刷新。
- 修复共享媒体中已加载照片的剧透效果重新开始及多余加载动画。
- 修复打开聊天时文件下载按钮颜色变化的问题。
- 重启提示移至系统导航区域上方，并缩短所有内置语言的提示文字。

### 贴纸与动画

- 修复缓存创建失败或取消时，动态贴纸一直加载的部分原因。
- 缓存失败后使用无缓存播放，避免无限重试。
- 修复动态贴纸和 WebM 的资源释放及后台任务取消。
