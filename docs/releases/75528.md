# NimarkoGram 12.10.1 (75528)

## 🇷🇺 Русский

- Исправлен статус обхода белых списков при смене аккаунта: если на устройстве есть одобренный аккаунт, повторная заявка не нужна.
- Статус доступа обновляется при одобрении, отзыве доступа и выходе из аккаунта. Уточнена инструкция: для заявки нужно фото или скриншот личного кабинета МегаФона/Yota.
- Исправлено смещение аватара в профиле при повороте экрана и изменении размеров окна, в том числе при открытии через главные вкладки.

## 🇬🇧 English

- Fixed restricted mobile network access status when switching accounts: no additional application is needed while an approved account remains signed in on the device.
- Access status now updates when access is approved, revoked or an account is signed out. Clarified the application instructions: attach a photo or screenshot of your MegaFon/Yota account page.
- Fixed the profile avatar shifting when rotating the screen or resizing the window, including profiles opened from the main tabs.
