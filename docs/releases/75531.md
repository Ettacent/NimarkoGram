# NimarkoGram 12.10.1 (75531)

## 🇷🇺 Русский

- Ускорен показ внутренних уведомлений: убрано ожидание системного оповещения.
- После показа уведомления в клиенте его системная копия больше не дублирует звук, вибрацию и всплытие.
- Подпись аккаунта отображается только для уведомлений с другого аккаунта.
- При новых сообщениях от того же собеседника имя больше не исчезает вместе с текстом.
- Исправлен расчёт высоты списков с форумами, вызывавший смещение панели папок.

---

## 🇬🇧 English

- In-app notifications now appear sooner, without waiting for system notification delivery.
- After an in-app notification is shown, its system copy no longer repeats the sound, vibration or pop-up alert.
- Account names are shown only for notifications received on another account.
- New messages from the same sender no longer fade out the sender's name together with the message text.
- Fixed forum-list height calculations that could shift the folder bar.

---

## 🇨🇳 简体中文

- 加快应用内通知的显示速度，无需等待系统通知发送。
- 应用内通知显示后，对应的系统通知不再重复播放声音、振动或弹出提醒。
- 仅在收到其他账号的通知时显示账号名称。
- 同一联系人发来新消息时，姓名不再随消息文本一起淡出。
- 修复论坛聊天列表的高度计算，避免文件夹栏发生偏移。
