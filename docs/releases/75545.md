🇷🇺 Русский

### Telegram 12.10.3

- Обновлена база Telegram до версии 12.10.3.

### Исправления и улучшения

- Исправлены отступы внутренних уведомлений и пустое место при переходах между поиском и списком чатов.
- Исправлены обновление данных инфокарточек, изменение их размеров и отображение рядом с папками.
- Доработаны заголовки и статусы чатов, переходы в профиль и отображение баннеров при смене аккаунта.
- Исправлено восстановление папок и архива после возврата в приложение.
- Доработаны сохранение индивидуальных звуков уведомлений, анимации настроек и подсветка результатов поиска.
- Исправлено переключение типов прокси: поля, описания и фон карточек меняются согласованно.
- Добавлены переводы описания WEB-прокси, включая русский и китайский.
- Убраны лишние разделители в меню профиля. Временная диагностика переходов удалена.
- Доработаны обход для МегаФона/Йоты и измерение задержки подключения.
- Улучшены переходы валют и статусов в инфокарточках, отображение длинных названий и индикаторов набора текста.
- Добавлено плавное появление загруженных эмодзи; исправлено обновление кадров встроенных видеопревью под верхней панелью.
- Снижена лишняя нагрузка при открытии окна обновлений и «Избранного».

🇬🇧 English

### Telegram 12.10.3

- Updated the Telegram base to version 12.10.3.

### Fixes and improvements

- Fixed in-app notification spacing and leftover gaps when switching between search and the chat list.
- Fixed info-card data refresh, resizing and placement alongside folders.
- Improved chat titles and statuses, profile transitions and banners when switching accounts.
- Fixed folder and archive restoration when returning to the app.
- Improved per-chat notification sound persistence, settings animations and search-result highlighting.
- Fixed proxy-type transitions so fields, descriptions and card backgrounds update together.
- Added WEB proxy description translations, including Russian and Chinese.
- Removed empty profile-menu separators and temporary transition diagnostics.
- Improved MegaFon/Yota bypass and connection latency measurement.
- Improved currency and status transitions in info cards, long chat titles and typing indicators.
- Added smooth loading transitions for emoji and fixed inline video frame updates beneath the top panel.
- Reduced unnecessary work when opening the update sheet and Saved Messages.

🇨🇳 简体中文

### Telegram 12.10.3

- Telegram 基础版本更新至 12.10.3。

### 修复与改进

- 修复应用内通知的间距，以及搜索与聊天列表切换后残留的空白。
- 修复信息卡片的数据刷新、尺寸变化及与文件夹并排显示的问题。
- 改进聊天标题、在线状态、个人资料过渡及切换账号后的横幅显示。
- 修复返回应用后文件夹和归档的恢复问题。
- 改进单独聊天的通知音保存、设置动画和搜索结果高亮。
- 修复代理类型切换，使输入框、说明和卡片背景同步变化。
- 补充 WEB 代理说明的翻译，包括俄语和中文。
- 移除个人资料菜单的多余分隔线及临时过渡诊断。
- 改进 MegaFon/Yota 网络绕过功能及连接延迟测量。
- 改进信息卡片的货币与状态切换、长聊天标题及输入状态指示。
- 为加载后的表情添加平滑过渡，并修复顶部面板下内嵌视频的帧更新。
- 减少打开更新面板和收藏夹时的额外处理。
