# NimarkoGram 12.10.1 (75532)

## 🇷🇺 Русский

- Исправлен статус автообновления: уже установленная версия больше не предлагается к повторной установке.
- Исправлены цвета, размытие и плавность появления теней внутренних уведомлений.
- Добавлен отступ между внутренним уведомлением и закреплённым сообщением.
- Убрана повторная анимация загрузки неизменившегося аватара. Новые фотографии по-прежнему появляются плавно.

---

## 🇬🇧 English

- Fixed the updater status: an installed version is no longer offered for installation again.
- Fixed in-app notification colors, blur rendering and shadow transitions.
- Added spacing between in-app notifications and pinned messages.
- Removed repeated loading animations for unchanged avatars. New photos still fade in smoothly.

---

## 🇨🇳 简体中文

- 修复自动更新状态：不再提示重复安装已安装的版本。
- 修复应用内通知的颜色、模糊效果和阴影过渡。
- 增加应用内通知与置顶消息之间的间距。
- 头像未改变时不再重复播放加载动画，新头像仍会平滑淡入。
